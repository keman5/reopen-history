## Reviewer notes adapted for Edge

```text
Requires desktop Microsoft Edge 120 or later. No account, login, subscription, API key or external service is required.

Testing:
1. Open a normal HTTPS webpage in a non-private Edge window, then close its tab.
2. Click the extension's toolbar button. The recently closed tab should reopen.
3. Close another HTTPS tab, then right-click the toolbar button and select the closed-tab history command. Verify that the entry appears and can be searched and reopened.
4. Open the extension's settings to test language selection, minimum font size and optional webpage context menus. Privacy and support pages are bundled and available offline.

Permissions:
- sessions: lists and restores recently closed browser sessions.
- tabs: reads tab titles and URLs for eligible records.
- storage: saves records and preferences locally.
- contextMenus: provides toolbar and optional webpage menu commands.
- favicon: uses the browser-local favicon cache for site icons.

There are no host permissions, content scripts, remotely hosted executable code, analytics or automatic transmission of browsing records. Opening a restored webpage loads its original website normally.

Browser-internal and non-HTTP(S) pages are excluded. Native restoration depends on Edge retaining the session; expired entries fall back to reopening the saved URL.
```
